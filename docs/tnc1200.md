# TNC1200 Host Harness

This document covers the M1.7 host-side TNC1200 integration harness. It connects the existing KISS parser, AX.25 framing, AFSK1200 streaming TX, and AFSK1200 streaming RX modules without hardware dependencies.

## Purpose

TNC1200 proves the portable modules can behave like a simple KISS TNC in deterministic host tests. It is not STM32 firmware, USB CDC device code, a PTT controller, or a real-radio interface.

## TX Pipeline

```text
KISS byte stream from host
	|
	KISS parser
	|
	KISS data command 0
	|
	raw AX.25 frame bytes with FCS
	|
	AFSK1200 streaming TX
	|
	signed 16-bit PCM chunks
```

`tnc1200_host_input()` accepts arbitrary chunks of KISS bytes. A decoded KISS data frame starts AFSK1200 TX if TX is idle. If TX is busy, the new frame is rejected and counted. There is no transmit queue in M1.7.

## RX Pipeline

```text
signed 16-bit PCM chunks
	|
	AFSK1200 streaming RX
	|
	raw AX.25 frame bytes with FCS
	|
	KISS data command 0
	|
	KISS byte stream to host
```

`tnc1200_rx_process()` accepts arbitrary PCM chunks and writes KISS data frames into the caller output buffer. If a decoded RX frame does not fit in the caller buffer, the KISS output is dropped and `rx_frames_dropped` is incremented.

## KISS Commands

| Command | M1.7 behavior                                  |
| ------- | ---------------------------------------------- |
| 0       | Data frame starts AFSK1200 TX                  |
| 1       | TXDELAY updates leading HDLC flag count        |
| 2       | P value is stored only                         |
| 3       | SlotTime value is stored only                  |
| 4       | TXtail updates trailing HDLC flag count        |
| 5       | FullDuplex value is stored only                |
| 6       | SetHardware payload is stored by KISS parser   |
| 255     | Return is a no-op                              |

Unsupported commands are ignored and counted by the KISS parser. P-persistence is not enforced in M1.7.

## Stats

The TNC1200 stats include:

- KISS frames in and out.
- KISS parse errors.
- Ignored KISS commands.
- TX frames started, done, and rejected.
- RX frames OK, bad FCS, malformed, and dropped.
- PCM samples in and out.

## Limitations

- Host-side deterministic vectors only.
- No p-persistence channel access.
- No DCD gating.
- No PTT control.
- No watchdog TX timeout.
- No USB CDC device code.
- No hardware audio path.
- No real-radio testing.
