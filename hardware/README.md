# Hardware

Hardware is not started in M0.

This directory is reserved for KiCad files, datasheet references, and simulations after documentation review.

Planned layout:

| Path           | Purpose                                  |
| -------------- | ---------------------------------------- |
| `kicad/`       | Future schematic and PCB project files   |
| `datasheets/`  | Local datasheet references where allowed |
| `simulations/` | Analog and signal integrity simulations  |

PCB work starts only after protocol, architecture, firmware safety, hardware block diagram, and test plan review.
